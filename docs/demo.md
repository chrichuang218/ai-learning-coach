# 一分钟看懂一次学习

![缓存学习过程重演](../assets/product/learning-loop.gif)

这是依据真实缓存测试和学习记录改编的 **48 秒流程重演**，不是新用户录像。测试输出经过精简；跑通测试不代表独立掌握。

1. 先预测：同进程扫描过空目录，新增文件后第二次会读到什么？
2. 再观察：目标测试验证缓存保持旧快照；重置后能读取新文件。
3. 留下边界：用户运行了提供的测试，独立设计仍待验证。
4. 下一次继续：从修改已有 Skill 内容这个相邻场景验证迁移。

重演的 [HTML 版本](demo/learning-loop.html) 可下载后离线打开，支持暂停、前后切换和键盘操作。GitHub 页面会显示源码，GIF 可直接观看。
