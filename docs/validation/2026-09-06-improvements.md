## 行为探针及局限

候选与旧版分别由独立新 agent 执行“过几天回来继续”和“把运行给定测试记成独立设计”两种场景。输入包含模拟上下文，没有提供可实际读取的源码；执行者不读取评分标准和对照结果。

两组均支持 **5/6** 项严格判据。运行给定测试的三项证据边界均满足；续学时均正确区分旧日期和近期证据，但在实际源码核验前给出了假设推演，严格“先核验再选动作”的顺序未证明。该项需要有真实文件的交互验收，不能把 context-only probe 当成源码核验成功。

本次没有证明模型行为优于旧版，更不能据此宣传学习效果提升。工程新增价值由上表的执行验证支持。精确模型 ID、完整 token 与耗时未从执行器提供，记录为不可用，不填零。

针对源码核验这项缺口，已另补一轮 [有真实文件的续学集成](../../evals/results/2026-09-06/resume-integration.md)：候选先核对了固定 HEAD、工作区状态和当前 `discoverSkills` 行号，再保留帮助边界并给一个预测动作。该次执行支持实际恢复路径可用；不回改先前 context-only 评分，也不据一次结果宣称跨模型稳定。
